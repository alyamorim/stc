Aguardando iniciar trabalho

Trabalhos já distribuídos, ainda não iniciados. Use Iniciar trabalho para começar a elaboração ou Registrar pendência se algo impede o início agora.

Trabalhos em curso

Trabalhos em elaboração. Escolha, em cada linha, para onde encaminhar: revisão TX, revisão GO, pendências ou relator.

Trabalhos pendentes

Trabalhos parados por alguma pendência. Edite o campo de observações para atualizar o motivo e use Enviar para trabalhos em curso quando for possível retomar.

Em revisão TX

Inclui também os trabalhos aguardando revisão da GRE. Use Enviar para revisão GO quando a TX concluir, ou Enviar para trabalhos em curso se precisar de ajuste seu antes.

Em revisão GO

Use Retornar para revisão TX se a GO devolver com apontamentos, ou Enviar para relator quando estiver pronto.

Enviado para o relator

A data pode ser ajustada diretamente na tabela. Use Aprovado pelo relator quando o relator se manifestar favoravelmente, ou Retornar para trabalhos em curso caso o parecer volte para ajuste.

Aprovado pelo relator

Marque Concluído se a aprovação já encerra o trabalho (deliberação conclusiva pela comissão), ou Em tramitação em outra comissão/Plenário se a proposição ainda seguirá adiante.

Em tramitação em outra comissão/Plenário

Ao marcar Concluído, um PL em 1º turno gera a pergunta sobre o 2º turno; os demais casos vão direto para os concluídos.

Concluídos

Trabalhos encerrados. Se algum precisar voltar à sua mesa, use Desarquivar para devolvê-lo à fila de espera.
